# Novalon House Studio releases

This repository stores versioned **desktop downloads** and, when implemented and tested, Android APK and iOS IPA builds. Source code, documentation and tests are saved in the private [Novo-Home repository](https://github.com/MiMat82/Novo-Home).

## Current Windows release

[Download Novalon House Studio 0.1.21](https://github.com/MiMat82/Nova-Home-releases/releases/tag/v0.1.21)

The portable Windows x64 ZIP includes the complete app, a two-floor 10 × 8 metre house with a grouped kitchen, and both floor plans as A3 PDF pages at 1:75. Extract the complete ZIP and keep the application files together. Launch `Novalon House Studio.exe` or `Open-grouped-kitchen.cmd`.

The application works offline without an account. Save designs as `.novahouse` files. Furniture groups, adjustable 2D/3D panes, compact avatar/immersive controls and shared A3 output are included. See the version's release notes and verification receipt for the tested scope.

Check downloaded files against `SHA256SUMS.txt`. The executable is unsigned. Physical printing, clean-machine installation and long-duration use are not verified. This is concept-planning software, without certified construction, complete BIM or regulatory compliance guarantees.

## Platforms

- Windows x64: available in 0.1.21.
- Android APK: not implemented or released yet.
- iOS IPA: not implemented or released yet.

Packages are GitHub Release assets. This repository's Git history stores small release notes, manifests and checksums. Published version assets are retained rather than overwritten.
